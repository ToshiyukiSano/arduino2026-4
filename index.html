「Class 6」など上の表にない名前のクラスは、送りません。Teachable Machine でクラス名を直し、学習し直して「Update my cloud model」を押してから、「モデルを再読み込み」を押します。
Teachable Machine で学習し直しただけでは、共有リンクのモデルは変わりません。「Export Model」→「Update my cloud model」で更新が終わってから「モデルを再読み込み」を押します。
追加撮影に戻るとき：AIを「一時停止」→②「カメラを止める」→TMで撮影・再学習・クラウド更新。TMの撮影欄を×で閉じ、PreviewのInputをOFFにしてから、このページで「モデルを再読み込み」→「カメラを使う」→「再開」。接続が切れていれば③でつなぎ直します。
更新が反映されないとき：TMで更新完了を確認→URLを確認→「モデルを再読み込み」。新しいURLなら欄に貼って「モデルを読み込む」。それでも直らなければ、この操作ページを開き直して①②③を設定します。TMのタブは残してください。
カメラ映像は鏡のように左右反転して表示されます。左右は「AIの判定」と、実際のサーボの動きで確かめます。
