# Arduino入門講座 第4回「手話やジェスチャーをAIで見分けて、Arduinoを操作しよう」教材

Arduino UNO R4 WiFi 用の教材です。ZIPをダウンロードしたら、必ず展開してから使います。
（これまでと同じ手順：このページの「Code」→「Download ZIP」→ 右クリック「すべて展開」）

> 【状態】スケッチは代替環境で文法と動きを確認し、操作ページは代役のAI・Bluetoothで画面の動きを確認しています。
> 実機（UNO R4 WiFi・LED・サーボ・カメラ・Chrome の Bluetooth 接続・Teachable Machine のモデル読み込み）での確認は、授業前に講師が行います。

## 入っているもの

| ファイル・フォルダー | 内容 |
|---|---|
| `dai4_ai_remote` | 操作ページから Bluetooth で1文字を受け取り、LED・サーボ・LEDマトリクスを動かす |
| `index.html` | 操作ページ。Teachable Machine のモデルを読み込み、カメラの手話・ジェスチャーを見分けて Arduino へ送る。展開したフォルダーの中のこのファイルを、PC の Google Chrome で開く |
| `dai4_0_led_check` | 外付けLED（D2〜D6）を順番に光らせて、配線を確かめる（困ったとき・発展） |

## 授業の進め方（3つのステージ）

1つずつ動きを確かめながら進めます。ステージが進んでも、**Arduino のプログラムは書き換えません**。操作ページの「割り当て」ボタンで、クラスごとに送る文字を切り替えます。

| ステージ | 使うもの | Teachable Machine のクラス（例） | 割り当てボタン | 動き |
|---|---|---|---|---|
| ① LED | 外付けLED 1個（D2）＋抵抗 | ジェスチャーA・ジェスチャーB・待機 | ① LED | A → 点灯（O）、B → 消灯（F） |
| ② サーボ | サーボ（D9・5V・GND） | ジェスチャーCを足して学習し直す | ② サーボ | A → 左（L）、B → 中央（C）、C → 右（R） |
| ③ マトリクス | 本体の LED マトリクス | 同じモデルのまま | ③ マトリクス | A → 絵1（ハート）、B → 絵2（にこにこ）、C → 絵3（矢印） |

- 待機（手を出していない）は、どのステージでも N（何も変えない）です。
- 割り当てボタンは、待機以外のクラスを**作った順**に使います（ステージ1は2個、ステージ2・3は3個まで）。順番は画面の右の欄で変えられます。
- 発展：LED を D3〜D6 に追加し、プログラムに1行足して LED を切り替える／S（順番に点灯）を使う／組み合わせて作品にする。

## 送る文字（dai4_ai_remote と index.html で同じ）

| 文字 | 動き | ステージ |
|---|---|---|
| `O` | LED（D2）点灯 | ① |
| `F` | LED（D2）消灯 | ① |
| `L`・`C`・`R` | サーボを左・中央・右へ（初めの値 180°・90°・0°） | ② |
| `1`・`2`・`3` | LED マトリクスに絵1・絵2・絵3 | ③ |
| `S` | LED を D2→D6 の順に1回ずつ点灯 | 発展 |
| `N` | 待機（何も変えない） | すべて |

Arduino は「L:0:180:NGS-01」（最後の文字:LED（1＝点灯）:角度:機器名）のように返事をします。
予備：シリアルモニター（9600）から同じ文字を送っても動きます。

## 配線

| ステージ | 部品 | Arduino のピン |
|---|---|---|
| ① | LED 1個 | D2 → 抵抗 → LED の＋（長い足）、LED の−（短い足）→ GND |
| ② | サーボ 信号（ふつうオレンジ）・＋（ふつう赤）・−（ふつう茶） | D9・5V・GND（第3回と同じ） |
| ③ | 本体の LED マトリクス | 配線なし |
| 発展 | LED を追加（黄・青・緑・白など） | D3・D4・D5・D6（それぞれ 抵抗 → LED → GND） |

- LED ごとに抵抗を1個入れます（1kΩ を候補。UNO R4 WiFi の I/O ピンは1本 8mA まで）。
- 配線を変えるときは、必ず電源を外してから行います。
- サーボの電源は第3回と同じく Arduino の 5V・GND から取ります（講師が使用するサーボで事前に確認する構成）。動作が不安定なとき（リセットする・震える）は、講師に知らせてください。

## dai4_ai_remote で変えるところ（「★ここを変える」の中だけ）

| 名前 | 初めの値 | 意味 |
|---|---|---|
| `DEVICE_NAME` | `"NGS-01"` | 機器名。先生から割り当てられた自分の番号（NGS-01〜NGS-11） |
| `ANGLE_LEFT`・`ANGLE_CENTER`・`ANGLE_RIGHT` | `180`・`90`・`0` | ステージ2：サーボの角度（0〜180） |
| `PICTURE_1`〜`PICTURE_3` | ハート・にこにこ・矢印 | ステージ3：LED マトリクスの絵（`#` が光る、`.` が消える。横12文字×縦8行） |

- `servo.attach(9)` は信号を出すピンの指定（setup で1回）、`servo.write(角度)` は角度の指定です。
- 発展：`handleCommand` の中の各ブロックに `ledOnly(YELLOW);`（その LED だけ光らせる）や `showPicture(PICTURE_1);` を1行足すと、動きを組み合わせられます。`ledOnly`・`showPicture` はこの教材で用意した関数で、`servo.write`・`digitalWrite` は Arduino の標準の命令です。

## 操作ページ（index.html）の使い方

1. Teachable Machine で学習したら「Export Model」→「Upload my model」を押し、表示された共有リンクをコピーする。
2. index.html を Chrome で開き、①の欄にリンクを貼り付けて「モデルを読み込む」。
3. ②「カメラを使う」→ カメラの使用を「許可」。手話・ジェスチャーを出してバーの長さを確かめる。
   - Teachable Machine のタブがカメラを使っているときは、そのタブを閉じます。
4. 「割り当て」のボタン（① LED／② サーボ／③ マトリクス）を押す。
5. ③「Bluetoothで接続」→ 一覧から自分の機器を選ぶ。
6. ④「AIで操作」を押して「有効」にする。「手で試す」のボタンで、AI を使わずに動作を確かめることもできます。

- 誤動作を減らすため、スコアが条件以上で、同じ判定が一定時間続いたときだけ、判定が変わったときに送ります（初めの値：0.8 以上・1 秒。画面で変更できます）。
- スコアは「どのクラスに近いと判定したか」の目安で、必ず正しい確率ではありません。
- 学習し直したら、新しい共有リンクで読み込み直します。
- 操作ページは AI のライブラリ（TensorFlow.js 1.3.1・Teachable Machine image 0.8）とモデルをインターネットから読み込みます。**授業中はインターネットが必要です。**

## 手話とジェスチャー

- 手話として紹介する表現は、先生や信頼できる資料で確認したものだけを使います。
- 自分たちで決めた操作用のポーズは「ジェスチャー」と呼んで区別します。
- このAIは、カメラの画像1枚ごとに「どのクラスに近いか」を判定するだけで、手話の文章や会話を理解する仕組みではありません。

## 使うときのきまり

- 書き込むとき：PC と Arduino を USB でつなぐ（書き込みと電源）。
- AI で動かすとき：PC の USB を外し、Arduino を USB 充電器などにつなぐ。LED マトリクスに番号が出てから接続する（つながるとチェックの絵になる）。
- コードを直すとき：「切断」→ USB 充電器から外す → PC と USB でつなぐ → 直して書き込む → USB 充電器につなぐ → 接続し直す。
- Bluetooth の設定画面でのペアリングは不要です。
- 第3回の操作ページとは別の番号（UUID）を使っています。第3回の index.html では第4回のプログラムにつながりません。
