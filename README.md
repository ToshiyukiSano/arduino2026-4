# Arduino入門講座 第4回「手話や手の形で操作するAIリモコンをつくろう」教材

Arduino UNO R4 WiFi 用の教材です。ZIPをダウンロードしたら、必ず展開してから使います。
（これまでと同じ手順：このページの「Code」→「Download ZIP」→ 右クリック「すべて展開」）

> 【状態】新規作成の教材です。スケッチは代替環境で文法を確認し、操作ページはスクリプトの文法とクラス名の判定だけ確認しています。
> 実機（UNO R4 WiFi・LED・サーボ・カメラ・Chrome の Bluetooth 接続・Teachable Machine のモデル読み込み）での確認は、授業前に講師が行います。

## 入っているもの

| ファイル・フォルダー | 内容 | 時間 |
|---|---|---|
| `dai4_ai_remote` | AI の判定（1文字）を Bluetooth で受け取り、外付けLED・LEDマトリクス・サーボ（・7セグ）を動かす | 2・3時間目 |
| `index.html` | 制御ページ。Teachable Machine のモデルを読み込み、カメラの合図を見分けて Arduino へ送る。展開したフォルダーの中のこのファイルを、PC の Google Chrome で開く | 2・3時間目 |
| `dai4_0_led_check` | 外付けLED（D2〜D6）を順番に光らせて、配線を確かめる（困ったときだけ） | 2時間目 |

## 全体のしくみ

```
カメラ → PC の AI（制御ページ）→ Bluetooth（1文字）→ Arduino → LED・マトリクス・サーボ
```

- AI の判定は PC の中で行います。Arduino に AI は入っていません。
- 送る文字：`A`（合図A）・`B`（合図B）・`C`（合図C）・`N`（待機）。Arduino は「A:0:NGS-01」のように返事をします。
- 制御ページは、AI のライブラリ（TensorFlow.js 1.3.1・Teachable Machine image 0.8）とモデルをインターネットから読み込みます。**授業中はインターネットが必要です。**
- 予備：シリアルモニター（9600）から A・B・C・N を送っても動きます。

## 基本の動き

| AI の判定 | 外付けLED | マトリクス | サーボ |
|---|---|---|---|
| 合図A（A） | 赤（D2） | 1 | 0° |
| 合図B（B） | 青（D4） | 2 | 180° |
| 合図C（C・応用） | 緑（D5） | 3 | 90° |
| 待機（N） | 消灯 | 点3つ | 今の角度のまま |

## 配線

| 部品 | Arduino のピン |
|---|---|
| LED 赤・黄・青・緑・白 | D2・D3・D4・D5・D6（それぞれ 抵抗 → LED の＋（長い足）、LED の−（短い足）→ GND） |
| サーボ 信号（ふつうオレンジ） | D9 |
| サーボ 電源＋（ふつう赤） | 5V |
| サーボ GND−（ふつう茶） | GND |
| 1桁7セグ a〜g（追加課題・選択） | D7・D8・D10・D11・D12・A0・A1（各セグメントに抵抗） |

- LED ごとに抵抗を1個入れます（1kΩ を候補。UNO R4 WiFi の I/O ピンは1本 8mA まで）。
- 配線を変えるときは、必ず電源を外してから行います。
- サーボの電源は第3回と同じく Arduino の 5V・GND から取ります（講師が使用するサーボで事前に確認する構成）。動作が不安定なとき（リセットする・震える）は、講師に知らせてください。
- 7セグは型番・共通アノード／共通カソード・足の配置を現物で確かめてから配線します。

## dai4_ai_remote で変えるところ（「★ここを変える」の中だけ）

| 名前 | 初めの値 | 意味 |
|---|---|---|
| `DEVICE_NAME` | `"NGS-01"` | 機器名。先生から割り当てられた自分の番号（NGS-01〜NGS-11） |
| `LED_A`・`LED_B`・`LED_C` | `RED`・`BLUE`・`GREEN` | 合図のときに光らせる LED（`RED` `YELLOW` `BLUE` `GREEN` `WHITE` `NONE`） |
| `LED_A2`・`LED_B2`・`LED_C2` | `NONE` | 2個目も光らせるときの色 |
| `ANGLE_A`・`ANGLE_B`・`ANGLE_C` | `0`・`180`・`90` | 合図のときのサーボの角度（0〜180） |
| `PICTURE_A`〜`PICTURE_C`・`PICTURE_WAIT` | 1・2・3・点3つ | LED マトリクスの絵（`#` が光る、`.` が消える。横12文字×縦8行） |
| `USE_7SEG` | `false` | 7セグを使うときだけ `true` |
| `COMMON_ANODE` | `false` | 共通アノードの7セグなら `true` |
| `DIGIT_A`〜`DIGIT_C` | `1`・`2`・`3` | 7セグに出す数字 |

- `servo.attach(9)` は信号を出すピンの指定（setup で1回）、`servo.write(角度)` は角度の指定です。

## 制御ページ（index.html）の使い方

1. Teachable Machine で学習したら「Export Model」→「Upload my model」を押し、表示された共有リンクをコピーする。
2. index.html を Chrome で開き、①の欄にリンクを貼り付けて「モデルを読み込む」。
3. ②「カメラを使う」→ カメラの使用を「許可」。合図を出してバーの長さを確かめる。
   - クラス名から送る文字（A・B・C・N）を自動で決めます。決まらなかったクラスは右の欄で選びます。
   - Teachable Machine のタブがカメラを使っているときは、そのタブを閉じるかカメラを止めます。
4. ③「Bluetoothで接続」→ 一覧から自分の機器を選ぶ。
5. ④「AIで操作」を押して「有効」にする。「手で試す」のボタンで、AI を使わずに動作を確かめることもできます。

- 誤動作を減らすため、スコアが条件以上で、同じ判定が一定時間続いたときだけ、判定が変わったときに送ります（初めの値：0.8 以上・1 秒。画面で変更できます）。
- スコアは「どのクラスに近いと判定したか」の目安で、必ず正しい確率ではありません。
- 学習し直したら、新しい共有リンクで読み込み直します。
- 最後に読み込んだリンクは、このPCのChromeに覚えておきます。

## 使うときのきまり

- 書き込むとき：PC と Arduino を USB でつなぐ（書き込みと電源）。
- AI で動かすとき：PC の USB を外し、Arduino を USB 充電器などにつなぐ。LED マトリクスに番号が出てから接続する。
- コードを直すとき：「切断」→ USB 充電器から外す → PC と USB でつなぐ → 直して書き込む → USB 充電器につなぐ → 接続し直す。
- Bluetooth の設定画面でのペアリングは不要です。
- 第3回の操作ページとは別の番号（UUID）を使っています。第3回の index.html では第4回のプログラムにつながりません。
